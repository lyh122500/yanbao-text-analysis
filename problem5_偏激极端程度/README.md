# 问题5：研报措辞强度与极端表达

**一句话**：把每篇研报里“话说得多绝对、多夸张”变成可计算的数。

**它测什么** —— 文本中七类措辞的**出现频率**。
**它不测什么** —— 不测分析师是否真的偏激、判断是否正确、是否缺乏理性。
这是**用词代理指标**，未经人工效度验证，数值不能直接解释为作者偏激程度。

---

## 一、整体流程

```
                       综合分析结果.xlsx
                      17,712 篇研报原文
                                │
                                ▼
        ┌──────────────────────────────────────────────┐
        │① 清洗 + 位置映射                             │
        │   去空白 / 软连字符 / 零宽字符               │
        │   记下每个字在原文中的位置                   │
        └──────────────────────────────────────────────┘
                                │  位置映射保证每条“证据”都能还原到原文
                                ▼
        ┌──────────────────────────────────────────────┐
        │② 建立掩码（从分子和分母一起扣除）            │
        │   · 公司简称 / 券商名                        │
        │   · 固定评级短语（强烈推荐 …）               │
        │   · 免责声明句                               │
        └──────────────────────────────────────────────┘
                                │
                                ▼
        ┌──────────────────────────────────────────────┐
        │③ 两级切分                                    │
        │   句   ：。！？!? 和 <?>     → 有效句数 S    │
        │   分句 ：再加 ，；：          → 匹配范围     │
        │   ⚠ 数字千分位不拆：1,234                    │
        └──────────────────────────────────────────────┘
                                │
                                ▼
        ┌──────────────────────────────────────────────┐
        │④ 词表匹配（135 词 / 7 维度）                 │
        │   最长优先 → “不可能”不会被拆成“可能”        │
        └──────────────────────────────────────────────┘
                                │
                                ▼
        ┌──────────────────────────────────────────────┐
        │⑤ 每条命中逐个判定                            │
        │                                              │
        │   被排除？ ──是──▶ active = False            │
        │   （4 类规则）     留证据、不计分            │
        │                                              │
        │   有语境标记？ ──是──▶ 退出“保守口径”        │
        │   （5 类标记）        仍计入“主口径”         │
        └──────────────────────────────────────────────┘
                                │
                                ▼
        ┌──────────────────────────────────────────────┐
        │⑥ 汇总两套口径                                │
        │                                              │
        │   主口径   = 未被排除                        │
        │   保守口径 = 未被排除 且 无语境标记          │
        │                                              │
        │   极端措辞 = 绝对化 + 夸张修辞               │
        │   强势措辞 = 极端 + 确定性 + 语气强化        │
        │                                              │
        │   密度   = 次数 × 1000 / 有效汉字数 H        │
        │   句占比 = 命中句数 / 有效句数 S             │
        └──────────────────────────────────────────────┘
```

**为什么"极端"不是全部七类之和**：`模糊性`是独立维度（不抵消强势措辞）、
`幅度表达`和`最高级`是辅助项（`最大股东`、`销量大幅增长`描述的是事实而非偏激），
这三类只单独输出，不计入两个总数。

## 二、七个维度

| 维度 | 词数 | 示例 | 计入哪个总数 |
|---|---:|---|---|
| 确定性 | 17 | 必将、必然、毫无疑问、不可能 | **强势** |
| 绝对化 | 8 | 绝不、永远、无一例外、不可逆转 | **极端 + 强势** |
| 夸张修辞 | 29 | 史无前例、前所未有、千载难逢、首屈一指 | **极端 + 强势** |
| 语气强化 | 15 | 非常、极其、极大、坚定看好 | **强势** |
| 模糊性 | 33 | 可能、预计、有望、不确定性 | 独立，不进总数 |
| 幅度表达 | 15 | 大幅、显著、暴跌、爆发式 | 辅助，不进总数 |
| 最高级与排他 | 18 | 最大、最高、唯一、百分之百 | 辅助，不进总数 |

完整词表见 `resources/lexicon.json`。这是**项目自建的窄表**，
不是 LM/LIWC 或其他成熟量表的翻译；中文词条、规则、公式均自行制定。

## 三、四个关键设计

**① 排除规则（4 类）——为什么不是简单词频统计**

同一个词在不同搭配里性质完全不同，这是本指标最容易出错的地方：

| 排除理由 | 例子 | 说明 |
|---|---|---|
| 金融术语或事实身份搭配 | `绝对估值`、`唯一上市平台`、`十分之一` | 技术术语，非修辞 |
| 绝对的歧义用法_待核 | `绝对比重` | “绝对”后无断言，标记待核 |
| 跨词误匹配 | `南北极高端` 里的 `极高` | 分词边界造成 |
| 前置否定_保守排除 | `不是极其乐观` | 否定改变了语义 |

**② 语境标记（5 类）——为什么有两套口径**

`同分句含模糊词` / `条件表达` / `疑似转述` / `疑问句` / `书名号引用`。
带标记的命中**仍计入主口径**（语境本身不等于错），但退出保守口径。

> 注意：转述、疑问是**整句级**判定。一句里出现“管理层表示”，
> 同句其他命中也会被打上“疑似转述”。所以保守口径偏严。

**③ 最长优先匹配**

`不可能` 优先于 `可能`——否则强断言会被记成模糊词；`前所未有` 优先于 `空前`。

**④ 不做段落删减**

问题2 剔除例行“风险提示”段的口径**不适用于本问题**——风险披露里也可能有
强势措辞。问题5 全篇分析，不删任何段落。

## 四、一条真实记录走完全流程

以 `源Excel行号=3`（2013-10-28 双鹭药业／国信证券）为例：

```
原文 → 清洗 → 掩码 → 切分 → 匹配 → 判定 → 汇总

有效汉字数 H = 723         （已扣除公司名、券商名、固定评级）
有效句数   S = 20

命中：确定性 1 次（无绝对化、夸张、强化命中）

  强势措辞次数 = 1
  强势措辞密度 = 1000 × 1 / 723 = 1.383
  强势措辞句占比 = 1 / 20 = 5%
  确定性占情态词比例 = 1 / (1 + 2) = 33.33%     ← 2 为模糊性次数
  幅度表达 2 次、最高级 1 次 → 不并入总数

本条无被排除、无语境待核命中 → 主口径与保守口径数值相同
```

读法要点：`33.33%` 是"确定性词在情态词中的份额"，**不是**整篇 33.33% 的句子都确定。

| `措辞证据.jsonl` | 一条 = 一次词面命中（含被排除的） | ❌ 36M，本地生成 |
| `逐篇指标.json` | 机器可读版逐篇结果 | ❌ 12M，本地生成 |
| `措辞核验样本.csv` | 一条 = 一份待人工核验的命中或空句 | ❌ 含原文，本地 |
| `词典扩展候选_待审核.csv` | 一条 = 一个词表扩展候选 | ✅ |
| `稀缺维度种子候选_待审核.csv` | 一条 = 一个稀缺维度候选（含审核结论） | ✅ |

**主结果表的列结构**（43 列，按块理解）：

| 列块 | 内容 |
|---|---|
| 1–7 | 源Excel行号 + 元数据（fordate／序号／stkcd／公司简称／证券公司）+ 计算状态 |
| 8–9 | 分母：有效汉字数 H、有效句数 S |
| 10–15 | 极端措辞与强势措辞的次数／密度／句占比（主口径） |
| 16–19 | 同上的保守口径（预期 ≤ 主口径） |
| 20 | 确定性占情态词比例 |
| 21–22 | 被排除命中数、语境待核命中数（两者互斥） |
| 23–43 | 七个维度各自三列：`X次数`／`X密度_每千汉字`／`X词面命中数` |

`X词面命中数` ≥ `X次数`：前者是排除前的匹配数，用于对照排除规则的影响。

**空值与零的区别**：`0` = 该口径未命中；**空白** = 分母为 0 无法定义，
不能用 0 替换。

## 七、词表扩展（稀缺维度）

词表原 125 词，但**绝对化（6 词）与夸张修辞（21 词）种子最稀缺**，故做了一轮扩展。
流程只保留**可从语料复现**的部分：

```
expand_scarce_seeds.py          逐种子 PPMI 上下文向量扩展
   （非"类别中心"——原方法在绝对化只有 1 个种子通过筛选时，中心退化成该词自身）
        │
        ├─ 产出 255 条候选
        │
        ▼
   频次过滤：只保留来自"频次≥10 的种子"的 84 条
        │    （绝无 全库仅 1 次，其"向量"即那一次的 ±3 词窗口，
        │      最近邻是 苯酚/氨基 —— 纯噪声）
        ▼
   3 次独立判断分类（≥2 方一致才入选）
        │
        ▼
   人工审核 → 采纳 10 词、驳回 8 词
```

**模型"凭知识提出"的候选一律剔除**：没有语料溯源（说不出由哪个种子、多少相似度
扩出来），不可复现也不可审计。判断结果作为**冻结输入**存于
`resources/独立判断结果.json`，SHA256 记入 manifest——与 `lexicon.json` 同为
固定输入，不破坏哈希链条。

**采纳 10 词**：夸张修辞 +8（历史性、空前、独具、首屈一指、绝佳、革命性、
举足轻重、无法比拟），绝对化 +2（总是、不可逆转）。

**驳回 8 词**：`巨大`(3,099次)、`强大`(980次) 仅 2/3 一致且量级失衡——
加入会使夸张修辞从 123 增至 4,629（37 倍），把该维度从稀缺渲染用语变成常见程度词；
`难得`、`遍布全国` 语义不符；`优势`/`龙头`/`领先`/`领先地位` 为条件性候选，
单独不是断言（单独计入会把全部 12,778 次"优势"算成绝对化）。

扩展影响（含同期"绝对"地位断言的修正）：极端措辞 151 → **844** 次，
绝对化 28 → 371、夸张修辞 123 → 473；有极端措辞的研报 141 → **714** 篇。
驳回理由已逐条写入 `output/稀缺维度种子候选_待审核.csv`。

## 八、已知局限

1. **`总是` 有 1 例分词歧义误判**——"**郎总**（郎先生）**是**极具管理才能…"
   被连读成"总是"。全库 `X总是` 共 17 次，误判率 5.9%，占绝对化类别 0.3%。
   修复需引入姓氏表，影响极小故暂未处理。
2. **`强烈` 的谓词用法**——628 次主口径命中中 334 次（53%）是
   "预期强烈""需求强烈"这类句末谓语，描述的是**市场预期**的强度，
   而非分析师的措辞力度。是否应排除属于口径选择，当前保留。
3. **词表覆盖面窄**——本批语料中仍存在未收录的极端表达，如
   `卓有成效`(79次)、`不可估量`(12次)、`异军突起`(9次)、`一马当先`(7次)。
4. **词典无权重、无人工效度验证**——所有词等权，数值是出现频率而非强度评分。
5. **行业文体与重复报告影响**——同一公司多篇、模板化段落会推高计数。
6. **软件一致性已检查，不等于测量效度已验证**。正式实证前需先审样本修词表，
   再在独立留出报告上验证误报漏报。不能用修规则的同一批样本证明准确率。

## 九、运行

```bash
cd problem5_偏激极端程度
python -m pip install -r requirements.txt

python problem5_extremity.py          # 计分（只依赖 openpyxl）
python -m unittest test_problem5.py   # 13 项单元测试
python verify_problem5.py             # 全量一致性核验

# 可选：词表扩展
python expand_scarce_seeds.py         # 稀缺维度候选池
python merge_seed_candidates.py       # 合并独立判断，生成待审核表
python expand_candidates.py           # 原有七维度候选
```

脚本支持 `--input` / `--output-dir`，主程序另支持 `--lexicon`。
跨问题合并用 `源Excel行号`（源数据的“序号”列不唯一，不能作主键）。

**复现**：`manifest.json` 锁定输入/程序/词表/证据/指标的 SHA256 及依赖版本。
相同冻结输入和依赖下，JSON 与证据文件字节一致；不要求含容器元数据的 XLSX 字节相同。

```bash
python problem5_extremity.py --output-dir /tmp/replay
python verify_problem5.py --replay-dir /tmp/replay
```

**产出规模**（实测）：计分 25 秒；稀缺维度候选池 55 秒；候选合并 6 秒；
七维度候选扩展 42 秒。词表或规则一改，`summary.json` 的统计、
`manifest.json` 的哈希、以及 Excel 数值都会变，须重新核验。

**审核结论存放位置**：`resources/种子审核结论.json`（冻结输入）。
`稀缺维度种子候选_待审核.csv` 的审核栏由该文件填入，
**不要直接改 CSV**——重跑会覆盖。新增裁定请改 JSON 后重跑合并脚本。
