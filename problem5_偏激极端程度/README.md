# 问题5：研报措辞强度与极端表达

## 怎么做

固定中文种子词表、金融语境排除规则、逐处原文证据；用本批研报构建上下文向量生成词表扩展候选。程序不调用大模型，不依赖问题1—4的输出。当前为自建词典代理指标，未经独立人工效度验证，不能把数值直接解释为作者偏激、判断错误或缺乏理性。

### 1. 七个维度分别计算

| 维度 | 示例 | 指标用途 |
|---|---|---|
| 确定性 | 必将、必然、毫无疑问、不可能 | 强势断言，允许肯定或否定判断 |
| 绝对化 | 绝不、永远、无一例外、不可逆转、特定断言中的绝对 | 极端措辞组成部分 |
| 夸张修辞 | 史无前例、前所未有、千载难逢、首屈一指、一枝独秀 | 极端措辞组成部分 |
| 语气强化 | 非常、极其、强烈、坚定看好 | 强势措辞组成部分 |
| 模糊性 | 可能、预计、有望、不确定性 | 独立保留，不直接抵消强势措辞 |
| 幅度表达 | 大幅、显著、暴跌、爆发式 | 辅助项，可能描述真实变化 |
| 最高级与排他表达 | 最大、最高、唯一、百分之百 | 辅助项，可能描述客观排名、身份或全量比例 |

完整种子表在`resources/lexicon.json`。这是项目自建中文表，不是LM/LIWC或其他成熟量表的翻译。概念参考[LM官方词典说明](https://sraf.nd.edu/loughranmcdonald-master-dictionary/)中强情态、弱情态与不确定性的区分，以及[汉语强化表达与情态必要性研究](https://www.routledge.com/Intensification-and-Modal-Necessity-in-Mandarin-Chinese/Wu/p/book/9780367596781)。中文词条、规则和公式均由本项目制定。

### 2. 针对当前数据消歧

- 不收单独的“一定”“确定”“完全”“异常”。“一定程度”“异常天气”“完全投产”容易误判；收“一定会”等具体短语。“不确定性”完整匹配。
- “强烈推荐”等固定评级短语、当前公司及券商名称，从计数和有效汉字数中一起扣除。只剔除触发明确免责声明规则的句子。固定评级小表并不覆盖全部券商评级。
- “绝对估值”“绝对收益”“绝对值”“绝对额”等**数量与估值术语**排除。其余“绝对”须紧邻断言才计入，分两类：**判断断言**（如“会、不会、是、低估、看好”）与**地位断言**（如“龙头、优势、领先、竞争、主导、垄断、主导、主力、保障、领导、市场”），对应“绝对龙头”“绝对优势”“绝对领先地位”这类全有全无的地位表述，与词表中“无一例外”“绝无”同类。泛指程度而无断言的用法（“绝对准确”“绝对比重”）仍标记歧义待核。完整规则见代码。

  注：修正前“优势/领先/龙头”曾被误并入金融术语排除表，导致 306 次修辞性用法被排除、涉及 268 篇；“绝对”主口径计数由 9 增至 317，有极端措辞的研报由 141 篇增至 404 篇。详见“已知问题与修正”。
- “唯一”放入辅助指标。单独的“预期”不计模糊性，避免“符合预期”误计；保留“预计”“预期将”“预期会”。
- 过滤“非常规”“十分之一”等专业或数量搭配；排除“南北极高端”“积极大力”等跨词误匹配。不把药名“西地那非”的末字单独当作否定词。
- 最长非重叠匹配；固定相邻否定模式下的命中保守排除，不机械反转类别。“不可能”“绝不”本身是完整的强断言词。
- 主口径保留语境中的措辞；保守口径额外排除带条件、模糊、转述、疑问或书名号引用标记的命中。条件及模糊看同分句，转述及疑问看整句，书名号引用按成对书名号定位，不能等同准确句法分析或引语归属。
- 匹配前去空白、软连字符及零宽字符，保存原文位置映射。句界为`。！？!?`和`<?>`；分句另用逗号、分号、冒号，保护数字千位逗号。小数点和普通换行不分句。

风险提示仍保留，模糊性可能受披露模板影响；没有从整篇强势词数中减去模糊词，因为两者可能指向不同命题。

### 3. 公式

`H`为去除名称、固定评级、明确免责声明后的汉字数（U+3400–U+4DBF、U+4E00–U+9FFF），`S`为仍有有效汉字的句数；数字和英文不进入分母。每个词的每次出现计一次。

```text
极端措辞次数 E = 绝对化次数 + 夸张修辞次数
强势措辞次数 F = E + 确定性次数 + 语气强化次数
极端措辞密度 = 1000 × E / H
强势措辞密度 = 1000 × F / H
极端措辞句占比 = 至少一次极端措辞的句数 / S
强势措辞句占比 = 至少一次强势措辞的句数 / S
确定性占情态词比例 = 确定性次数 / (确定性次数 + 模糊性次数)
```

保守口径分子额外排除语境待核命中，分母不变。七分项分别输出有效次数、每千汉字密度及未经排除调整的词面命中数。不设置“轻度／重度偏激”阈值，不拼凑0–100综合分。

有效正文零命中时密度为0；无正文时密度与比例留空。没有情态词时情态比例留空。少于100汉字或3句标记“短文本_谨慎比较”，保留数值供筛选。

建议先检查强势措辞密度及保守口径，极端措辞密度作为较窄指标，保留各分项供研究设计选择。极端词稀疏、行业文体、篇幅、重复报告和模板可能影响结果。

### 4. 确定性的词表扩展

`expand_candidates.py`实现“种子—语料扩展—审核”，以PPMI共现向量替代随机训练的Word2Vec。固定参数：规范化后整篇完全相同文本去重；jieba 0.42.1、HMM=False并注册种子；按标点、非汉字边界分片段；左右3词窗口；最小词频20；最多10,000候选词、3,000上下文词；按频数排序、词典序打破并列。

```text
PPMI(w,c) = max(0, log(共现次数 × 总共现数 / (行总数 × 列总数)))
```

词向量L2归一化，各类合格种子取均值再归一化；余弦相似度取Top30，并列按词典序。最多210行，跨类别可能重复。上下文相似不保证同义或同强度，“大幅”附近可能出现“小幅”。**候选文件不会被计分程序读取**；须人工审词、审例句、定维度与排除搭配，升级词表版本后重新计算，当前审核栏全部留空。

全期语料扩展仅适合当前历史样本的探索性词表构建。如需样本外评价或避免未来信息，应只从训练期生成并审核，再冻结用于后续时期。基础计分不依赖扩展结果。

## 输出怎么读：每一行代表什么

主结果表的工作表名为`措辞指标`。第1行是表头，第2—17,713行分别对应原始Excel第2—17,713行的研报，**一行代表一篇输入研报记录**；缺失文本也保留一行，不删行、不合并同公司报告。只要不排序或筛掉记录，输出与原表行序一致；排序后须使用`源Excel行号`关联。该行号仅在相同源文件版本下有效。

同一公司可有多个日期、多个券商的多篇研报，同一份文本也可能重复出现；计分时均按原记录保留。只有词典扩展阶段对规范化后全文相同的文本去重。原始“序号”不是唯一键。

### 状态、空值和零值

| 计算状态 | 判定规则 | 如何使用这一行 |
|---|---|---|
| 可计算 | H≥100且S≥3。 | 保留全部指标；此状态不代表人工验证通过。 |
| 短文本_谨慎比较 | H>0，但H<100或S<3。 | 数值照算，短篇少量命中会造成较大密度，可在研究中单独标记或做剔除对照。 |
| 占位文本 | 清理后等于“无”“暂无”“无内容”“无有效内容”或nan/none/null（不区分英文大小写）。 | H、S及次数为0，密度和比例为空；不能解释为作者使用了温和措辞。 |
| 空白或无汉字 | 内容为空，或清理后没有统计范围内的汉字，且不是上一类占位文本。 | 同样保留记录、密度及比例为空。 |
| 有效正文为空 | 输入有汉字，但名称、评级或免责声明遮罩处理后H=0。 | 该分支可能仍有被排除的词面证据；密度及比例为空。当前这批数据未出现此状态。 |

有效文本中的0表示该口径未命中；空单元格表示分母为0、无法定义，不能用0直接替换。任何密度都按每千汉字计，任何句占比及情态词比例都在0—1之间，以百分数显示。极端措辞次数＝绝对化次数＋夸张修辞次数；七类词面命中数之和＝七类有效次数之和＋被排除命中数。

### 一条真实结果的读法

`源Excel行号=3`对应2013-10-28的双鹭药业／国信证券记录。H=723、S=20，确定性1次、模糊性2次，没有绝对化、夸张或强化命中，因此：

- 强势措辞次数为1，密度为`1000×1/723=1.383125864…`，Excel显示1.383。
- 只有1句命中强势措辞，所以强势措辞句占比为`1/20=5%`。
- 确定性占情态词比例为`1/(1+2)=33.33%`，这不是整篇33.33%的句子都确定。
- 幅度表达2次、最高级与排他表达1次，均不并入强势或极端总数。
- 本条无被排除或语境待核命中，主口径与保守口径数值相同。

## 证据、核验样本与扩展候选：每一行的意义

### 措辞证据.jsonl

每个物理行是一个JSON对象，代表**某篇原文中的一次词面命中**，不是一篇研报。相同词在同篇不同位置出现会有多行；被排除的命中也保留。无词面命中的研报不会出现在这个文件里。

| 字段 | 含义 |
|---|---|
| source_row | 原始Excel物理行号，与主结果表关联。 |
| term | 去空白和软连字符后匹配到的词典词。 |
| category | 英文类别键：certainty=确定性、absolute=绝对化、hyperbole=夸张修辞、intensity=语气强化、hedge=模糊性、magnitude=幅度表达、superlative=最高级与排他表达。 |
| start / end | 命中在原始字符串中的起点／终点，Python字符索引，从0开始、含起点不含终点；不是Excel列号、字节偏移或汉字序号。 |
| raw_match | `原始文本[start:end]`，可能包含软换行或空格，所以不一定与term字面完全一样。 |
| sentence_id | 按固定句界得到的句子序号，从1开始；按分句前的句序编号，不因遮罩后失去有效汉字而重新编号，不能用最大编号替代有效句数。 |
| clause_start / clause_end | 所在标点分句在原文中的字符区间，同样为从0开始的左闭右开区间。 |
| clause | 对应原文分句，可用于复核词义和上下文。 |
| excluded_reason | 未进入主口径的理由；空字符串表示没有被排除。多种排除条件同时成立时仅保留程序优先命中的理由，不重复计数。 |
| context_flags | 语境标记列表，可含“同分句含模糊词”“条件表达”“疑似转述”“疑问句”“书名号引用”，可同时多项；它们是规则标记，不是人工结论。 |
| active | true表示计入该类别的主口径，false表示只保留词面证据。 |
| strict | true表示active为true且context_flags为空，可进入该类别的保守口径。辅助类别即使strict为true，也不会进入强势或极端总数。 |

排除理由包括“当前公司或券商名称”“固定评级名称”“免责声明句”“金融术语或事实身份搭配”“跨词误匹配”“绝对的歧义用法_待核”“前置否定_保守排除”。最后两项是保守规则处理，不代表已经人工确认词义。

### 措辞核验样本.csv

一行代表**一条待核验命中或一条无命中句**。每层最多30条的固定抽样，不是全部证据，也不是简单随机抽样的研报集合。

| 字段 | 含义与填写方式 |
|---|---|
| 抽样层 | 无语境标记的有效命中按类别分层；其他层为语境待核、某种排除理由或无词面命中句。 |
| 源Excel行号 | 回查整篇研报的行号。 |
| 原文起点 / 原文终点 | 命中字符区间；无命中样本则为整个抽样句的区间。从0开始、左闭右开。 |
| 词条 | 规则匹配词；无命中句留空。 |
| 建议类别 | 程序词表类别；无命中句留空，不能直接当作人工标签。 |
| 规则计入 | true表示计入主口径，false表示已排除或该句没有词面命中。 |
| 排除理由 | 当前规则排除该命中的原因，未排除时为空。 |
| 语境标记 | 该命中的语境标记，用分号连接；无标记则为空。 |
| 原文上下文 | 命中前最多60字符、命中后最多80字符的上下文；无命中层给出整句。信息不足时回原表读取整篇。 |
| 人工是否有效 | 留给真人填写。命中样本判断是否确实表达该类措辞；无命中句判断是否存在漏识别的目标表达。建议填“是／否／待定”，在备注说明判断对象。 |
| 人工类别 | 真人确认的维度；如与建议类别不同，写更正类别。没有对应表达时留空。 |
| 标注人 | 实际核验者的姓名或可追溯代号；程序不代填。 |
| 备注 | 记录语义歧义、遗漏词、错误边界、需补充上下文等。 |

### 词典扩展候选_待审核.csv

一行代表**某个维度下的一条扩展候选**。同一个词可以出现在不同维度，不代表应重复收录。相似度不是置信概率、措辞强度或经过验证的词典标签。

| 字段 | 含义与填写方式 |
|---|---|
| 建议维度 | 用于计算种子中心的类别，即候选可能归属的维度。 |
| 排名 | 该维度内按上下文余弦相似度降序的名次；分数并列按词典序，默认最多30条。 |
| 候选词 | 语料分词得到、尚不在当前种子表中的词。 |
| 语料频数 | 规范化全文去重后，按固定jieba分词统计的出现次数，不是包含它的研报篇数，也不等于主程序的词面计数。 |
| 上下文余弦相似度 | 候选PPMI向量与该维度种子中心的余弦相似度。相似只说明使用环境接近，可能包括反义词或主题词。 |
| 是否收入词典 | 人工审核栏，建议填“是／否／待定”，初始为空。填“是”也不会自动修改计分词表。 |
| 审核后维度 | 人工确认的类别；可以更正建议维度。 |
| 审核人 | 实际审核者姓名或代号，初始为空。 |
| 备注 | 收录／拒绝原因、需要的消歧规则和限制条件。 |
| 语料例句 | 最多两条采集上下文，标明原表行号；同一行内可能含换行。每段最多展示160字符，可能截掉候选词，须按行号回原文确认。 |

### 其余机器文件

- `逐篇指标.json`：JSON数组中的一个对象对应一篇报告，不是“一个物理文本行一篇”。`source_row`对应原表行号；`status/han/sentences`对应状态、H、S；`counts/raw_counts`分别为七类有效次数／词面次数。`extreme_count/strong_count`为两类总次数，`extreme_sentences/strong_sentences`为命中句数，`strict_`前缀表示保守口径。`excluded_count/context_count`对应主表第21／22列。
- `summary.json`：整批数据汇总。`documents`为记录数，`status`为各状态记录数，`category_counts`为各类主口径总次数，`excluded`为各排除理由的命中次数，`top_terms`为主口径词频前30。`review_samples`为核验样本条数，`reports_with_extreme/reports_with_strict_extreme`为两种口径至少有一次极端命中的报告数；`validation`说明没有人工准确率。
- `manifest.json`：本次主程序运行清单。`version/python/openpyxl`记录版本；`input_sha256/script_sha256/lexicon_sha256`锁定输入、程序及词表；`evidence_sha256/metrics_sha256`用于对比证据和指标是否相同；`sampling/offsets`记录抽样规则及字符位置约定。SHA256不是随机种子或统计指标。
- `expansion_manifest.json`：候选扩展运行清单，记录方法、输入及程序／词表／jieba内置字典哈希、依赖版本、HMM、窗口、最低词频、Top-N、词库上限及停用词；`vocabulary/contexts`为实际向量矩阵行／列规模，`used_seeds`为实际参与各维度中心计算的种子，`cooccurrence_nonzero`为共现矩阵非零项数，`duplicate_documents_skipped`为全文去重跳过的记录数，`candidates/candidate_sha256`为候选行数及校验值。`status`说明候选尚未审核。
- `verification.json`：最近一次核验记录。`documents/events`为核验的报告数／词面证据数；`source_offsets_exact/aggregation_and_excel_values/all_sentence_shares_in_range`是程序检查结果；`replay_hash_matches`逐文件记录与重跑结果的哈希是否相同，未指定重跑目录时为空字典；`manifest_sha256`标记核验对应的主程序清单；`validation_scope`限定为软件一致性。

GitHub提交程序、种子词表、README、依赖、主结果Excel及小型JSON清单。原始Excel、包含原文的证据与核验CSV、以及大型逐篇JSON保留在本地，可用脚本重新生成。仓库不包含人工审核结论。

## Python怎么运行

实测Python 3.9.13。主程序只需openpyxl，扩展才需其余依赖。

```bash
cd problem5_偏激极端程度
python -m pip install -r requirements.txt
python problem5_extremity.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python expand_candidates.py

```

脚本支持`--input`、`--output-dir`，主程序另支持`--lexicon`。原Excel只读，默认保留日期、股票代码、公司及券商。跨问题用`源Excel行号`对齐，不能用重复的“序号”。

```bash
python problem5_extremity.py --output-dir /tmp/yanbao_problem5_replay
python verify_problem5.py --replay-dir /tmp/yanbao_problem5_replay
```

`manifest.json`记录数据、程序、词表、指标、证据SHA256及版本；扩展清单额外记录jieba内置词典SHA256、参数、实际种子与候选SHA256。相同冻结输入及依赖下比较JSON和证据字节，不要求带容器元数据的XLSX字节相同。

### 词表扩展（稀缺维度）

词表原有 125 词。针对**绝对化（6 词）与夸张修辞（21 词）**两个种子最稀缺的维度做扩展，
流程分两步，**只保留可从语料复现的那一步的产出**：

1. **语料候选池** `expand_scarce_seeds.py`：逐种子 PPMI 上下文向量扩展
   （非“类别中心”——原方法在绝对化只有 1 个种子通过筛选时，中心退化成该词自身）。
   产出 255 条候选。
2. **独立判断筛选 + 人工审核**：每个候选配真实语料语境，由 3 次独立判断分类，
   ≥2 方一致才进入待审核表；再由人工逐条裁定。

**模型“凭知识提出”的候选一律剔除**：这类词没有语料溯源（说不出由哪个种子、

`resources/独立判断结果.json`，其 SHA256 记入 manifest——与 lexicon.json 同为
固定输入，不破坏确定性与哈希链条。

**已采纳 10 词**（详见 `output/稀缺维度种子候选_待审核.csv` 的审核栏）：

### 已知问题与修正

**“绝对”的地位断言曾被误并入金融术语排除表。** 原排除式
`绝对(?:估值|收益|…|控股|控制|优势|领先|龙头)` 把两类搭配混在一起：数量与估值术语
（绝对估值、绝对收益、绝对值、绝对额）应当排除，但地位断言（绝对龙头、绝对优势、
绝对领先）是全有全无的强度表述，与词表中“无一例外”“绝无”同类，误排会让最窄也最核心的
极端措辞维度接近空转——修正前“绝对”916次词面命中中主口径只计入9次。

已修正：排除式删除 `优势|领先|龙头`；歧义规则的断言词表补入地位类断言
（龙头、优势、领先、竞争、领军、主导、主力、保障、垄断、领导、市场）。

影响与验证：

| 指标 | 修正前 | 修正后 |
|---|---:|---:|
| “绝对”主口径计数 | 9 | 317 |
| 绝对化次数合计 | 28 | 336 |
| 极端措辞次数合计 | 151 | 459 |
| 有强势措辞的研报 | 4,059 | 4,225 |
| 有极端措辞的研报 | 141 | 404 |
| 有严格极端措辞的研报 | 132 | 381 |

全量 diff 验证：268篇逐篇指标发生变化，**全部只在 `absolute` 计数上变化、词面命中数一
个未变**（说明只改了排除判定，未新增任何匹配），其他字段0变化；证据层事件集合
116,924条完全一致，308条由未计入翻转为计入、**0条反向翻转**；新计入的317条
经逐条核对，无一条属于数量/估值术语。
