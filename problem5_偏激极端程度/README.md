# 问题5：研报语言的偏激程度和极端程度

**需求**（需求文档第 5 条）：衡量研报语言的偏激程度与极端程度。

## 怎么做（计划）

需求文档给出两条技术路线：

1. **词典扩充法**：找确定性词语词典和措辞强度词典做种子词 → 在大规模研报语料上
   训练词向量 → 取与种子词余弦相似度最高的 Top-N 词人工审核后加入词典 →
   用扩充词典识别文本中的确定性/模糊性词、最高级/绝对化词、夸张修辞、强度词；
2. **多 LLM 交集法**：用多个大语言模型阅读全文，各自整理确定性词、模糊性词、
   最高级/绝对化词、夸张修辞、强度词词表，多模型结果取交集形成自制词表。

可结合：用 LLM 词表与词向量扩充结果互相印证，最终输出偏激/极端程度得分。
