# 问题2：研报文本的情绪分析

**需求**（需求文档第 2 条）：对研报文本的叙事特征进行情绪分析。
需求原文提到“用中文情感词典啥的”，并给出词典来源
[MengLingchao/Chinese_financial_sentiment_dictionary](https://github.com/MengLingchao/Chinese_financial_sentiment_dictionary)。

## 怎么做（方法）

### 词典

采用该仓库提供的《中文金融情感词典_姜富伟等(2020).xlsx》：
**正面词 3,194 个、负面词 5,621 个**。词典自带 21 个正负重叠词
（如“激进”“出乎意料”“大胆”），语义歧义，计入任一侧都会引入噪声，
故从两侧同时剔除，实际使用**正面 3,173 + 负面 5,600**。

引用要求（词典“说明”页原文）：

> Fuwei Jiang, Joshua Lee, Xiumin Martin, and Guofu Zhou. "Manager Sentiment and
> Stock Returns" *Journal of Financial Economics* 132(1), 2019, 126-149.
> 姜富伟，孟令超，唐国豪. 媒体文本情绪与股票回报预测. 经济学(季刊).

词典文件不入版本库（见项目根 `.gitignore`），运行前需放入 `dict/` 目录，
下载地址见 `problem2_sentiment.py` 的报错提示。

### 处理流程

1. **分词**：jieba 分词，并把全部词典词注册进 jieba 用户词典，
   保证长词（如“不及预期”）不被切碎；
2. **匹配**：逐 token 比对词典，得到正面/负面词频；
3. **排除公司名**：词典里的词会命中公司简称——“沧州**明珠**”的“明珠”（正面）、
   “中国**平安**”的“平安”、“首航**节能**”的“节能”。用 `jieba.tokenize` 拿到
   字符位置，剔除落在**公司简称出现位置**内的命中。实测影响 513 行、
   1,199 次命中，受影响行的净值平均偏差 2.13（约 8%）；
4. **否定处理**（口径 2）：情绪词前 3 个 token 内出现否定词则翻转极性，
   遇标点停止（不跨句）。奇偶计数以支持双重否定（“并非不理想”不翻）。
   语料中“否定词+正面词典词”共 3,132 次、覆盖 13.8% 的研报，
   不做处理会把“不理想”记成正向；实际发生翻转的有 4,452 行（25.1%）；
5. **剔除风险披露段**（口径 3）：研报结尾的“风险提示/风险因素/投资风险”等
   是例行强制披露，不是分析师观点。语料中“风险”二字的出现**有 93.3%
   落在该段内**（15,823/16,964 次），63.9% 的研报命中“风险”，
   会系统性拉低负面净值。按首个章节标题截断，只用正文重算。

### 三套口径

| 口径 | 说明 |
|------|------|
| **1. 原始计数** | 忠于词典的词袋计数，与姜富伟等原论文口径一致 |
| **2. 否定调整** | 在口径 1 基础上处理否定式 |
| **3. 正文口径** | 在口径 1 基础上剔除风险提示段（**推荐用于刻画分析师语气**） |

三套口径都做了公司名排除与正负重叠词剔除。哪套适合回归由使用者的研究设计决定，
故同时输出。注意口径 2 与 3 未叠加（未做“否定调整 + 剔风险段”的组合）。

## 做了什么（输出）

`output/问题2_情绪分析结果.xlsx`，17,712 行 × 28 列：

## 结果如何

### 总体分布

| 指标 | 均值 | 中位数 | P25 | P75 | 最小 | 最大 |
|------|------|--------|-----|-----|------|------|
| 情绪净值 | 25.93 | 23.0 | 13 | 34 | -51 | 330 |
| 情绪比例 | 0.79 | 0.80 | 0.71 | 0.89 | 0.05 | 1.00 |
| 情绪密度（每 100 分词） | 8.03 | 7.90 | 6.55 | 9.43 | 0 | 27.27 |

情绪极性（口径 1）：正面 68.13%、中性 28.50%、负面 3.11%、无情绪词 0.26%。
换口径 3（剔风险段）后正面升至 73.62%、负面降至 2.74%，符合“风险提示段拉低情绪”的预期。

词典命中总量：正面词 623,176 次、负面词 163,856 次（约 3.8:1）。

### 与问题1评级的交叉校验

各评级下的平均情绪净值（越高越正面）：

| 评级 | 样本数 | 净值_原始 | 净值_否定调整 | 净值_正文 |
|------|--------|-----------|---------------|-----------|
| 推荐 | 5,409 | 29.01 | 28.52 | 29.34 |
| 买入 | 6,737 | 26.91 | 26.52 | 27.74 |
| 增持 | 2,842 | 23.51 | 23.01 | 24.21 |
| 中性 | 580 | 9.50 | 8.78 | 9.95 |
| 持有 | 296 | 6.46 | 5.83 | 8.03 |
| 卖出 | 27 | 3.07 | 2.56 | 2.85 |

**三套口径下均保持单调**：`卖出 < 持有 < 中性 < 增持 < 买入 ≈ 推荐`。
情绪指标是独立于评级提取的（评级靠规则抽档位、情绪靠词典计数），
两者的单调一致性说明指标确实捕捉到文本的正负倾向。

两点值得注意：

1. **“推荐”略高于“买入”**。可能是券商风格差异——使用“推荐”档位的券商
   行文更乐观，用“买入”的更克制。做实证时若混用两档需留意；
2. **评级与情绪存在明显背离的样本**。净值最低的几篇里，
   沙钢股份（净值 -51）评级是“推荐”、云南城投（-48）评级是“推荐”——
   业绩大幅下滑但分析师仍维持评级。这正是中文研报“报喜不报忧”的体现，
   也说明情绪与评级是两个不同的维度，不宜互相替代。

### 验证做了什么

- **冒烟测试**：正/负/否定/双重否定四类构造句，计数与极性均正确
  （`并非不理想` 正确判为不翻转）；
- **交叉校验**：上表的单调性，是本次最主要的有效性证据；
- **极端样本判读**：净值最低 5 行逐条读原文核对——
  光大证券（“8.16 内幕交易”的 `损失/诉讼/罚款/处罚/内幕`）、
  紫金矿业（`渗漏事故/污染`）、沙钢股份（`亏损/齐跌/低迷`）均属实；
- **否定分支核对**：抽 8 行有翻转的样本，`现金流未改善`、`运行尚不稳定`、
  `价格亦没有下降` 均被正确翻转；
- **改动全量 diff**：加入公司名排除后逐行比对，513 行变化与事前测量值
  完全一致（正面 -1,147、负面 -52），17,199 行计数未变，
  变化最大的样本（首航节能去“节能”、华夏幸福去“幸福”）均为预期的修正。

## 已知局限

1. **词典的领域错配**。词典由通用财经文本训练，会误收一些在本语料中
   不是情绪词的条目，例如产品名 `隔膜`（电池隔膜）在负面表里；
   反之 `扩张`（产能扩张通常正面）也在负面表里。这类条目无法用规则识别，
   只能靠人工审词典，本脚本未做词典层面的删改（保持词典原貌以便复现）；
2. **公司名排除是精确匹配**。只在正文出现**完整公司简称**时生效；
   简称本身被拆分或用了别名（如“中行”“招行”）时无法排除；
3. **否定窗口是固定 3 个 token**。“业绩好不好还不好说”这类复杂结构会误判；
   双重否定只做了奇偶计数，未处理“不得不”“无不”等固定搭配；
4. **风险段截断依赖章节标题**。语料中 63.9% 的研报含“风险”字样，
   其中 89% 能定位到标题；找不到标题的（约 1,200 行）口径 3 等同于口径 1；
5. **极性分档阈值（0.75/0.45）是人为设定**的，不属于词典方法的一部分。
   做回归建议直接用连续的 `情绪净值` 或 `情绪比例`，而非分档变量；
6. **源数据质量**：46 行“无情绪词”中有 4 行原文就是字面 `无`（ST鞍钢），
   属于源数据问题。

## 运行

```bash
cd problem2_情绪分析
# 需先下载词典到 dict/ 目录（见脚本报错提示中的地址）
python problem2_sentiment.py
```

依赖：`jieba`、`openpyxl`（见项目根 `requirements.txt`）。全量 17,712 行约 1 分钟。
