# 问题2：研报文本的情绪分析

**需求**（需求文档第 2 条）：对研报文本的叙事特征进行情绪分析。
需求原文提到“用中文情感词典啥的”，并给出词典来源
[MengLingchao/Chinese_financial_sentiment_dictionary](https://github.com/MengLingchao/Chinese_financial_sentiment_dictionary)。

## 怎么做（方法）

### 词典

采用该仓库提供的《中文金融情感词典_姜富伟等(2020).xlsx》：
**正面词 3,194 个、负面词 5,621 个**。词典自带 21 个正负重叠词
（如“激进”“出乎意料”“大胆”），语义歧义，计入任一侧都会引入噪声，
故从两侧同时剔除，实际使用**正面 3,173 + 负面 5,600**。

引用要求（词典“说明”页原文）：

> Fuwei Jiang, Joshua Lee, Xiumin Martin, and Guofu Zhou. "Manager Sentiment and
> Stock Returns" *Journal of Financial Economics* 132(1), 2019, 126-149.
> 姜富伟，孟令超，唐国豪. 媒体文本情绪与股票回报预测. 经济学(季刊).

词典文件不入版本库（见项目根 `.gitignore`），运行前需放入 `dict/` 目录，
下载地址见 `problem2_sentiment.py` 的报错提示。

### 处理流程

1. **分词**：jieba 分词，并把全部词典词注册进 jieba 用户词典，
   保证长词（如“不及预期”）不被切碎；
2. **匹配**：逐 token 比对词典，得到正面/负面词频；
3. **排除公司名**：词典里的词会命中公司简称——“沧州**明珠**”的“明珠”（正面）、
   “中国**平安**”的“平安”、“首航**节能**”的“节能”。用 `jieba.tokenize` 拿到
   字符位置，剔除落在**公司简称出现位置**内的命中。实测影响 513 行、
   1,199 次命中，受影响行的净值平均偏差 2.13（约 8%）；
4. **否定处理**（口径 2）：情绪词前 3 个 token 内出现否定词则翻转极性，
   遇标点停止（不跨句）。奇偶计数以支持双重否定（“并非不理想”不翻）。
   语料中“否定词+正面词典词”共 3,132 次、覆盖 13.8% 的研报，
   不做处理会把“不理想”记成正向；实际发生翻转的有 4,452 行（25.1%）；
5. **剔除风险披露段**（口径 3）：研报的“风险提示/风险因素/投资风险”等
   是例行强制披露，不是分析师观点。语料中“风险”二字的出现**有 93.3%
   落在该段内**（15,823/16,964 次），63.9% 的研报命中“风险”，
   会系统性拉低负面净值。
   实现上按源数据的段落分隔符 `<?>` 分段，**只删除含风险标题的那一段**。
   不能简单地“从头截断到风险标题处”——风险段并不总在末尾：
   10,113 篇可定位风险段的研报中，581 篇（5.7%）风险段位于 50%~80% 处、
   76 篇（0.8%）位于 50% 之前，其后还有真正的正文。
   例：广田集团某篇 8 段，风险标题在第 2 段，其后还有 6 段正文——
   截断法只统计到前 1.5 段（净值 -3），分段删除法则保留全部正文（净值 55）。

### 三套口径

| 口径 | 说明 |
|------|------|
| **1. 原始计数** | 忠于词典的词袋计数，与姜富伟等原论文口径一致 |
| **2. 否定调整** | 在口径 1 基础上处理否定式 |
| **3. 正文口径** | 在口径 1 基础上剔除风险提示段（**推荐用于刻画分析师语气**） |

三套口径都做了公司名排除与正负重叠词剔除。哪套适合回归由使用者的研究设计决定，
故同时输出。注意口径 2 与 3 未叠加（未做“否定调整 + 剔风险段”的组合）。

## 做了什么（输出）

`output/问题2_情绪分析结果.xlsx`，17,712 行 × 27 列。
**本产出不依赖任何其他问题的结果**，可独立运行；若需与其他问题的产出合并，
按**行号**对齐即可（源数据的“序号”列不唯一，17,712 行只有 1,496 个不同值，
不能作主键）。

### 列字典

数值列分三组，靠**后缀**区分口径。无后缀 = 口径 1（全文原始计数），
`_否定调整` = 口径 2，`_正文` = 口径 3。三组同名指标的定义完全相同，
只有统计范围不同。

**一、标识列**（6 列，直接来自源数据）

| 列 | 含义 | 备注 |
|----|------|------|
| `fordate` | 研报日期 | |
| `序号` | 源数据的序号 | **不唯一**（17,712 行仅 1,496 个不同值），不可作主键 |
| `stkcd` | 股票代码 | |
| `公司简称` | 被分析公司 | |
| `证券公司` | 发布研报的券商 | |
| `研报字数` | 源数据自带的字数 | 与 `分词数` 口径不同（约为其 2 倍），仅作参考 |

**二、口径 1 指标**（7 列，全文 + 不处理否定 + 不剔风险段）

| 列 | 含义 | 计算方式 | 本样本取值范围 |
|----|------|----------|----------------|
| `分词数` | 文本长度 | jieba 分词后的词数，**下述所有比例的分母** | 0 ~ 6,428（0 为原文为空） |
| `正面词数` | 命中正面词典的词次 | 逐词比对词典计数 | 0 ~ 404 |
| `负面词数` | 命中负面词典的词次 | 同上 | 0 ~ 151 |
| `情绪词数` | 情绪词总量 | `正面词数 + 负面词数` | 0 ~ 538 |
| `情绪净值` | 正负相抵后的差 | `正面词数 - 负面词数` | -51 ~ 330 |
| `情绪比例` | 情绪词中正面的占比 | `正面词数 / 情绪词数` | 0.05 ~ 1；**无情绪词时为空**（46 行） |
| `情绪密度` | 用词的情绪化程度 | `情绪词数 / 分词数 × 100`（每 100 个词的情绪词数） | 0 ~ 27.273 |

⚠️ `情绪净值` 与篇幅强相关（r = 0.689），**不要跨篇直接比较**；详见“指标怎么选”。

**三、口径 2 指标**（5 列，在口径 1 上叠加否定处理）

| 列 | 含义 |
|----|------|
| `正面词数_否定调整` | 口径 2 的正面词数（被否定翻转而来的负面词不计入） |
| `负面词数_否定调整` | 口径 2 的负面词数 |
| `情绪净值_否定调整` | `正面词数_否定调整 - 负面词数_否定调整` |
| `情绪比例_否定调整` | `正面词数_否定调整 / (正面词数_否定调整 + 负面词数_否定调整)` |
| `否定翻转词数` | 本行**因否定词而翻转极性**的词数；为 0 时口径 2 与口径 1 完全相同 |

**四、口径 3 指标**（4 列，在口径 1 上叠加剔除风险提示段）

| 列 | 含义 |
|----|------|
| `正面词数_正文` | 剔除例行“风险提示”段后的正面词数 |
| `负面词数_正文` | 同上，负面词数 |
| `情绪净值_正文` | `正面词数_正文 - 负面词数_正文` |
| `情绪比例_正文` | `正面词数_正文 / (正面词数_正文 + 负面词数_正文)` |

注：口径 2 与口径 3 **未叠加**，没有“否定调整 + 剔风险段”的组合列。

**五、分档列**（3 列，便于分组比较）

| 列 | 含义 |
|----|------|
| `情绪极性` | 按 `情绪比例` 分档：≥ 0.75 → `正面`；≤ 0.45 → `负面`；之间 → `中性`；无情绪词 → `无情绪词` |
| `情绪极性_否定调整` | 按 `情绪比例_否定调整` 分档，规则同上 |
| `情绪极性_正文` | 按 `情绪比例_正文` 分档，规则同上 |

阈值 0.75 / 0.45 是人为设定，不属于词典方法的一部分，仅适合粗略分组。

**六、复核列**（2 列，供人工抽查）

| 列 | 含义 |
|----|------|
| `正面命中词` | 本行**出现次数最多的 8 个**正面词，分号分隔。不等于该行全部正面词 |
| `负面命中词` | 同上，负面词 |

### 一行实例（一致药业，国信证券 2011-03-22）

| 列 | 值 | 怎么来的 |
|----|----|---------|
| 研报字数 / 分词数 | 885 / 441 | 源数据字数 vs jieba 分词数 |
| 正面词数 / 负面词数 | 31 / 5 | 逐词匹配词典 |

| 情绪净值 | 26 | 31 − 5 |

| 情绪密度 | 8.163 | 36 / 441 × 100 |

| 正面命中词 | 实现;增长;雄心;远超;优异;发展;兼备;推荐 | 本行最高频的 8 个正面词 |

## 结果如何

### 总体分布

（口径 1，全文原始计数）

| 指标 | 均值 | 中位数 | P25 | P75 | 最小 | 最大 |
|------|------|--------|-----|-----|------|------|
| 情绪净值 | 25.93 | 23.0 | 13 | 34 | -51 | 330 |
| 情绪比例 | 0.79 | 0.80 | 0.71 | 0.89 | 0.05 | 1.00 |
| 情绪密度（每 100 分词） | 8.03 | 7.90 | 6.55 | 9.43 | 0 | 27.27 |

平均一篇研报：566 个分词、44 个情绪词（正面 35.2 + 负面 9.3）。
⚠️ `情绪净值` 与篇幅强相关，**不要跨篇直接比较**——见下文“指标怎么选”。

情绪极性（口径 1）：正面 68.13%、中性 28.50%、负面 3.11%、无情绪词 0.26%。
换口径 3（剔风险段）后正面升至 73.70%、负面降至 2.71%，符合“风险提示段拉低情绪”的预期。

词典命中总量：正面词 623,176 次、负面词 163,856 次（约 3.8:1）。

### 自洽性对照：实测比例 vs 词典随机基线

词典本身是**负面词更多**的（正面 3,173 : 负面 5,600）。如果情绪词在文本中
随机出现，正面占比应该是 `3173/(3173+5600) = 0.362`。

实测**中位数 0.818，是随机基线的 2.3 倍**：

```
P 1  0.342      P25  0.711      P75  0.892
P 5  0.500      P50  0.818      P95  0.963
P10  0.585      P90  0.939      P99  1.000
```

说明研报用词是**系统性偏正面**的，而非随机分布——这是指标确有区分力的
一个自洽证据（不需要借助任何外部信息）。即使在第 5 百分位（最负面的 5%），
正面占比也有 0.50。

### 指标怎么选（重要）

三套口径 × 多个指标共 22 个数值列，容易挑错。按用途推荐：

| 用途 | 用哪个 | 原因 |
|------|--------|------|
| **回归/相关性分析** | **`情绪比例`** | 已按篇幅归一化，与分词数相关系数仅 0.031 |
| 想要"文本情绪强度" | `情绪密度` | 每 100 分词的情绪词数，与正负方向无关，可与比例组合使用 |
| 分档做分组比较 | `情绪极性` | 阈值 0.75/0.45 是人为设定，仅适合粗略分组 |
| ~~直接对比不同研报~~ | ~~`情绪净值`~~ | ⚠️ **绝对计数之差，与篇幅强相关（r = 0.689）** |

`情绪净值` 的陷阱用数据说明（口径 1）：

| | 平均分词数 | 平均净值 |
|---|---|---|
| 最短 25% 研报 | 331 | 15.0 |
| 中间 50% | 476 | 23.1 |
| 最长 25% 研报 | 980 | **42.5** |

长研报的净值天然更大，直接跨篇比较等于在比篇幅。如确要用，须把篇幅作为
控制变量，或改用比例。

另外两点：

1. **比例与密度是正交的两个维度**——一个说"方向"（偏正面还是偏负面）、
   一个说"强度"（写得多情绪化），可以同时放进模型，不必二选一；
2. **这些都是相对指标**，没有"多正面算正面"的绝对标准，0.818 只是本样本内的
   相对位置。做跨样本比较（如跟其他语料对比）时，须用同一词典、同一口径
   重算基准，不能直接套用本表的数值。

### 验证做了什么

- **冒烟测试**：正/负/否定/双重否定四类构造句，计数与极性均正确
  （`并非不理想` 正确判为不翻转）；
- **自洽性对照**：上表的“实测比例 vs 词典随机基线”，0.818 对 0.362；
- **极端样本判读**：净值最低 5 行逐条读原文核对——
  光大证券（“8.16 内幕交易”的 `损失/诉讼/罚款/处罚/内幕`）、
  紫金矿业（`渗漏事故/污染`）、沙钢股份（`亏损/齐跌/低迷`）均属实；
- **否定分支核对**：抽 8 行有翻转的样本，`现金流未改善`、`运行尚不稳定`、
  `价格亦没有下降` 均被正确翻转；
- **解耦验证**：临时移走其他问题的全部产出后重跑，脚本正常运行，
  17,712 行结果与移走前逐值一致（仅少一列来自其他问题的输入）；
- **改动全量 diff**（两次）：
  ① 加入公司名排除后，513 行变化与事前测量值完全一致
  （正面 -1,147、负面 -52），17,199 行计数未变，变化最大的样本
  （首航节能去“节能”、华夏幸福去“幸福”）均为预期修正；
  ② 把风险段处理从“截断”改为“按段删除”后，437 行正文口径计数变化，
  **全文口径 0 行变化**（确认改动只影响口径 3）；
  变化最大的样本（广田集团 净值 -3→55）经核实是此前误丢正文所致。

## 已知局限

1. **词典的领域错配**。词典由通用财经文本训练，会误收一些在本语料中
   不是情绪词的条目，例如产品名 `隔膜`（电池隔膜）在负面表里；
   反之 `扩张`（产能扩张通常正面）也在负面表里。这类条目无法用规则识别，
   只能靠人工审词典，本脚本未做词典层面的删改（保持词典原貌以便复现）；
2. **公司名排除是精确匹配**。只在正文出现**完整公司简称**时生效；
   简称本身被拆分或用了别名（如“中行”“招行”）时无法排除；
3. **否定窗口是固定 3 个 token**。“业绩好不好还不好说”这类复杂结构会误判；
   双重否定只做了奇偶计数，未处理“不得不”“无不”等固定搭配；
4. **风险段处理依赖段落分隔符与标题**。语料中 63.9% 的研报含“风险”字样，
   其中 89% 能定位到标题；找不到标题的（约 1,200 行）口径 3 等同于口径 1。
   另外，“只删含标题那一段”在风险条目与正文**混在同一段内**时，
   会连同段内标题之后的正文一起丢弃（如“风险提示：A；B。<正文继续>”这种写法），
   此类段落结构无法用规则区分；
5. **极性分档阈值（0.75/0.45）是人为设定**的，不属于词典方法的一部分。
   做回归建议直接用连续的 `情绪净值` 或 `情绪比例`，而非分档变量；
6. **源数据质量**：46 行“无情绪词”中有 4 行原文就是字面 `无`（ST鞍钢），
   属于源数据问题。
