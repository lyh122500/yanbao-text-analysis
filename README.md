# 研报文本进一步分析项目

依据《需要对研报文本进行的进一步分析.docx》的需求，对 `综合分析结果.xlsx` 中
“研报文本”列（17,712 行，2009–2016 年 A 股研报）做进一步分析。

**组织方式：每个问题一个文件夹**，脚本、README 与输出都在各自文件夹内，
原始 Excel 只读不改。各问题 README 按“怎么做 → 做了什么 → 结果如何”组织。

## 问题1：评级提取（已完成）

**怎么做**：以“评级”一词为锚点的规则提取 + 兜底句式（详见
[problem1_评级提取/README.md](problem1_评级提取/README.md)）。
**做了什么**：输出每行研报的 `评级_原始`、`评级_标准化`、`评级动作`、`提取证据`、`提取状态`。
**结果如何**：

- 17,712 行中成功提取 **15,896 行（89.75%）**；
- 标准化评级分布：买入 42.38%、推荐 34.03%、增持 17.88%、中性 3.65%、持有 1.86%、卖出 0.17%、观望/减持 <0.1%，符合当时 A 股研报“报喜不报忧”的总体特征；
- 质量验证：全量 diff 比对 + 自动化一致性排查 + 分层抽样人工判读 200+ 行（完整证据句）；
  验证中发现并修复 11 类缺陷，详见
  [problem1_评级提取/README.md](problem1_评级提取/README.md#质量验证做了哪些没做哪些)；
- 其余 9.8% 中，72 行是分析师**主动声明不给评级**（中金式“未有评级”、“暂不给予评级”等），
  1,732 行是**规则未抓到**（无评级词 / 股东增持等干扰 / 档位不在正文），两者性质不同，
  详见 [问题1 README 的说明](problem1_评级提取/README.md#未提取到评级与未给出评级的区别)。

## 问题2：情绪分析（已完成）

**怎么做**：jieba 分词 + 姜富伟等(2020)中文金融情感词典（正面 3,173 / 负面 5,600 词）
逐词计数，并做了公司名排除、否定处理、剔除风险披露段三层修正（详见
[problem2_情绪分析/README.md](problem2_情绪分析/README.md)）。
**做了什么**：输出三套口径的情绪指标（原始 / 否定调整 / 正文），
共 28 列，含净值、比例、密度、极性分档与命中词（供复核）。
**结果如何**：

- 情绪净值均值 25.93（中位数 23），情绪比例中位数 0.818；
  极性分布：正面 68.1%、中性 28.5%、负面 3.1%；
- 自洽性对照：词典本身负面词更多（正 3,173 : 负 5,600），随机基线比例为 0.362，
  实测中位数是它的 **2.3 倍**——研报用词系统性偏正面；
- 关键发现：`风险` 二字 93.3% 出现在研报的**例行风险提示段**，
  63.9% 的研报命中它，会系统性拉低负面净值，故提供剔除该段的口径；
  按段落删除该段后正面占比 68.1%→73.7%；
- ⚠️ **选用指标有讲究**：`情绪净值` 与篇幅强相关（r=0.689），不可跨篇直接比较；
  做回归请用已归一化的 `情绪比例`，详见问题2 README 的“指标怎么选”；
- 验证：冒烟测试、极端样本逐条读原文、否定分支抽查、改动全量 diff
  （513 行变化与事前测量值完全一致）、移走其他问题产出后独立运行验证。

## 各问题相互独立

**每个问题可单独运行、单独使用，不依赖其他问题的产出。**

- 各脚本只读取项目根目录的 `综合分析结果.xlsx`，输出写到自己文件夹的 `output/`；
- 各问题的输出都保持源数据的**行序**，需要横向合并时按行号对齐即可
  （源数据的“序号”列不唯一，17,712 行只有 1,496 个不同值，不能作主键）；
- 问题2 曾读取问题1的评级做过交叉校验，现已解耦：评级列已从产出中移除，
  相关验证改为不依赖外部信息的自洽性对照（词典随机基线）。

## 数据注意点（所有问题脚本通用）

- 源文件 1 个 sheet（Sheet1），17,712 行数据 + 1 行表头；
- **“序号”列不唯一**（17,712 行只有 1,496 个不同序号），不能当主键，跨文件对齐请按行号；
- “研报文本”列含 `<?>` 段落分隔符、软连字符（U+00AD）、被换列截断的词（如
  “评 级”被拆断、“评级”只剩“评”）等脏数据，处理前应先清洗；
- 文本长度参考 wordcount 列（数百到数千字）。
