# 问题1：研报评级提取

**需求**（需求文档第 1 条）：在研报文本列提取出分析师对被分析公司的评级，
例如：买入、增持、谨慎增持、卖出等等（包括但不限于这些）。

## 怎么做（方法）

以“评级”一词为锚点的规则提取，共 7 类锚点句式 + 4 类兜底句式：

### 锚点句式（文本中出现“评级”一词时，在其前后窗口内找评级词）

| # | 句式 | 示例 |
|---|------|------|
| 1 | “评级”之后出现“至/到/为 + 评级词” | `下调评级至中性-B`、`评级由买入下调为持有`、`评级仍为买入` |
| 2 | “评级”之后紧跟“：/为/动作词 + 评级词” | `投资评级：增持`、`评级仍为买入` |
| 3 | 评级词位于“评级”之前（最常见） | `维持“买入”评级`、`买入-A 投资评级`、`首次给予“强烈推荐”评级` |
| 4 | 全文扫描“加入X名单” | `我们将其加入买入名单` |
| 5 | 全文扫描截断句式（原文换列把“评级”截断） | `维持“谨慎推荐”评[2013上半年…]` |
| 6 | 全文扫描“建议X” | `建议买入`、`建议投资者增持`、`建议现价积极买入` |
| 7 | 全文扫描句尾裸评级词 | `……维持推荐。`、`强烈买入！`、`继续坚定推荐！` |

### 兜底句式（文本中无有效“评级”锚点时）

- `维持/继续/重申 + 评级词`：`维持“推荐”。`（“增持”单独处理，排除股东增持股份）；
- `给予/首次给予 + 评级词`：`首次给予“推荐”。`、`给予“买入”的投资建议`；
- `维持强推` 等缩写（“强推”= 强烈推荐，排除“强推广/强推品种”）。

### 评级词表与标准化

- 词表：买入 / 增持 / 推荐 / 强推 / 中性 / 持有 / 减持 / 卖出 / 回避 / 观望，
  可带前缀（强烈 / 谨慎 / 审慎）与后缀（-A / -B / -C，如安信的“买入-A”）；
- 标准化：去掉前缀后缀映射到基准档位（`买入-A→买入`、`强烈推荐→推荐`、
  `谨慎增持→增持`），原文保留在 `评级_原始` 列；
- 评级动作：维持 / 给予 / 上调 / 下调 / 重申 / 建议 / 调整 / 首次 / 纳入 等。

### 防误判

- 股东行为：“大股东增持/增持至20%”“公司持有XX%股权” → 排除；
- 词语干扰：“推荐逻辑”“推荐顺序”“中性施胶剂”“营改增持续推进”（增+持跨词）→ 排除；
- 券商评级标准说明段（如“平安证券综合研究所投资评级：”后跟多档位说明）→ 识别并跳过；
- `暂不给予评级 / 暂无投资评级 / 未有评级` → 单独标记“未给出评级（文中明确未给）”；
- 一条文本出现多处评级时按打分选最优候选：有动作词 +30、至-句式 +20、
  附近出现“公司简称” +40（多股票研报归属判定）、位置靠后 +pos/1000。

### 文本清洗

- **连接符归一化**：软连字符（U+00AD）、全角 `－`、`—` `–` `−` 等统一成 ASCII `-`。
  软连字符在语料里有两个用途且都表示“-”：`买入\xadA`（档位后缀，65 处）与
  `2010\xad2012 年`（年份区间，71 处），因此是转为 `-` 而非删除；
- **引号归一化**：除 `“”` 外，语料还夹着 `‚‛’‘‟「」` 等冷门引号约 300 处，
  统一成 `"`；
- 删除零宽字符等不可见字符；合并被换行拆散的“评 级”。

## 做了什么（输出）

`output/问题1_评级提取结果.xlsx`，17,712 行，列：

| 列 | 说明 |
|----|------|
| fordate / 序号 / stkcd / 公司简称 / 证券公司 / 分析师姓名 | 原始信息 |
| 评级_原始 | 文中原词（如“买入-A”“强烈推荐”“谨慎增持”） |
| 评级_标准化 | 基准档位（买入/推荐/增持/中性/持有/减持/卖出/回避/观望） |

### “未提取到评级”与“未给出评级”的区别

两者性质不同，下游使用时应区别对待：

- **未给出评级（72 行）= 分析师主动声明不给评级**，是确切的结论。两种来源：
  中金报告抬头的 `双鹭药业(002038.CH/人民币52.85, 未有评级)` 惯例，
  以及正文里的 `暂不给予评级`/`暂不评级`/`暂无评级`/`不予评级`/`无投资评级`
  （原因多为停牌高位、重大重组未定、超募资金投向未公布）。
- **未提取到评级（1,732 行）= 规则没抓到，是未知**，不是“无评级”。构成：
  完全无评级词 68%、含评级词但属股东增持等非评级用法 21%、含“评级”字样但
  档位不在正文（评级标准说明表、中金式“维持评级不变”）10%。

判定顺序：先尝试提取；提不到时再找“不给评级”的声明，有声明才算“未给出评级”。

### 质量验证（做了哪些、没做哪些）

**方法**：① 逐行 diff 比对（每次改动前后全量对比，确保变化可解释）；
② 自动化一致性排查；③ 分层随机抽样逐条人工判读（**完整证据句**，非截断窗口）。

**自动化排查**（全量 15,896 行）：证据中出现明确的 `X评级` 但输出档位不是 X
共 7 行（0.044%），逐条核对后 5 行实为正确（`由买入下调为增持`、
`下调至“中性”（原为“买入”）` 等提取的是目标档位，扫描把证据里的旧档位
当成了矛盾），2 行确为残余问题（见下）。`评级_原始` 未出现在证据中 0 行。

**抽样人工判读**：最终版本按提取句式分层抽样，累计判读 200+ 行（含截断句式
全量 76 行逐条读过），未发现错误。覆盖到的边界：全角破折号 `买入－B`、
软连字符 `买入\xadA`、档位间带空格 `“ 中性- A”`、冷门引号 `‚谨慎推荐‛`、
`（原为“买入”）` 等。

**验证中发现并修复的 11 类缺陷**（初版 README 曾写“抽查全部正确”，该表述不成立）：

| # | 缺陷 | 表现 / 案例 |
|---|------|-------------|
| 1 | 打分权重失衡 | 公司名加分(+40)压过动作词(+30)，`维持“买入”评级，积极推荐` 取成“推荐”（瑞普生物） |
| 2 | 兜底未排除动词用法 | `继续推荐机构投资者“买入”` 取成“推荐”（大北农） |
| 3 | `continue` 短路候选生成 | `给予“买入”评级，继续强烈推荐` 的正确候选根本没生成（碧水源/福耀玻璃/大华股份） |
| 4 | `至\|到\|为` 中“为”匹配到“**原为**” | `下调至“中性”（原为“买入”）` 把作废的旧评级当成新评级（黄山旅游） |
| 5 | 句式3 只取锚点前最后一个评级词 | `A股谨慎买入和H股买入评级` 丢掉 A 股档位（中国银行） |
| 6 | A/H/B 股双评级归属 | 45 行多市场档位取到了 H/B 股档位（中国太保/中信银行/招商地产） |
| 7 | 引号字符集不全 | `‚谨慎推荐‛` 等冷门引号（语料约 300 处）导致漏抓（华数传媒） |
| 8 | 截断模式间隔过严 | `维持公司“谨慎推荐”的投资评` 漏抓（武汉健民/五粮液/章源钨业） |
| 9 | 裸评级未排除情态动词 | `长期内仍可推荐。` 被当评级（建峰化工） |
| 10 | 兜底未排除股东增持 | `将继续增持公司股票` 被当评级（德威新材） |
| 11 | 连接符未归一化 | 软连字符 U+00AD 被直接删除，`买入\xadA` 变成“买入A”，**72 行档位后缀丢失**；全角 `－`、`—` 同样未处理 |

改动全部经全量 diff 校验：72 行补回后缀、6 行漏抓转为正确提取、2 行误判移除，
无其他档位变化。

## 已知局限（残余）

1. **A/H 股归属**：约 2 行仍存疑。如中国中铁 `维持谨慎买入评级。H 股存相对
   A 股估值溢价原因，持有评级保持不变`——“持有”指向 H 股，但“A 股”二字离它更近，
   就近规则判反。此类句子结构（市场标签与档位不在同一分句）无法用就近规则解决；
2. **同一报告多档位**：如荃银高科 `短期给予中性评级，中长期给予公司推荐评级`，
   取哪一个取决于研究口径，规则取了靠后的“推荐”；
3. **一份研报覆盖多只股票**时，优先取带动作词、靠近“公司简称”、位置靠后的候选，
   可能偶有归属偏差，请以“提取证据”列复核；
4. 少数报告评级档位完全不在正文中（如“维持评级不变”“跟踪评级”），无法从
   文本中恢复，标记为未提取。

**复核建议**：任何下游使用前，建议按 `提取状态` 分层抽样核对 `提取证据` 列；
A/H 股双重上市标的（银行、保险、基建类居多）建议单独抽查。
