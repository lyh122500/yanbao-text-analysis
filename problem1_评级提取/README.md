# 问题1：研报评级提取

**需求**（需求文档第 1 条）：在研报文本列提取出分析师对被分析公司的评级，
例如：买入、增持、谨慎增持、卖出等等（包括但不限于这些）。

## 怎么做（方法）

以“评级”一词为锚点的规则提取，共 7 类锚点句式 + 4 类兜底句式：

### 锚点句式（文本中出现“评级”一词时，在其前后窗口内找评级词）

| # | 句式 | 示例 |
|---|------|------|
| 1 | “评级”之后出现“至/到/为 + 评级词” | `下调评级至中性-B`、`评级由买入下调为持有`、`评级仍为买入` |
| 2 | “评级”之后紧跟“：/为/动作词 + 评级词” | `投资评级：增持`、`评级仍为买入` |
| 3 | 评级词位于“评级”之前（最常见） | `维持“买入”评级`、`买入-A 投资评级`、`首次给予“强烈推荐”评级` |
| 4 | 全文扫描“加入X名单” | `我们将其加入买入名单` |
| 5 | 全文扫描截断句式（原文换列把“评级”截断） | `维持“谨慎推荐”评[2013上半年…]` |
| 6 | 全文扫描“建议X” | `建议买入`、`建议投资者增持`、`建议现价积极买入` |
| 7 | 全文扫描句尾裸评级词 | `……维持推荐。`、`强烈买入！`、`继续坚定推荐！` |

### 兜底句式（文本中无有效“评级”锚点时）

- `维持/继续/重申 + 评级词`：`维持“推荐”。`（“增持”单独处理，排除股东增持股份）；
- `给予/首次给予 + 评级词`：`首次给予“推荐”。`、`给予“买入”的投资建议`；
- `维持强推` 等缩写（“强推”= 强烈推荐，排除“强推广/强推品种”）。

### 评级词表与标准化

- 词表：买入 / 增持 / 推荐 / 强推 / 中性 / 持有 / 减持 / 卖出 / 回避 / 观望，
  可带前缀（强烈 / 谨慎 / 审慎）与后缀（-A / -B / -C，如安信的“买入-A”）；
- 标准化：去掉前缀后缀映射到基准档位（`买入-A→买入`、`强烈推荐→推荐`、
  `谨慎增持→增持`），原文保留在 `评级_原始` 列；
- 评级动作：维持 / 给予 / 上调 / 下调 / 重申 / 建议 / 调整 / 首次 / 纳入 等。

### 防误判

- 股东行为：“大股东增持/增持至20%”“公司持有XX%股权” → 排除；
- 词语干扰：“推荐逻辑”“推荐顺序”“中性施胶剂”“营改增持续推进”（增+持跨词）→ 排除；
- 券商评级标准说明段（如“平安证券综合研究所投资评级：”后跟多档位说明）→ 识别并跳过；
- `暂不给予评级 / 暂无投资评级 / 未有评级` → 单独标记“未给出评级（文中明确未给）”；
- 一条文本出现多处评级时按打分选最优候选：有动作词 +30、至-句式 +20、
  附近出现“公司简称” +40（多股票研报归属判定）、位置靠后 +pos/1000。

### 文本清洗

去掉软连字符（U+00AD）等隐形字符、统一引号、合并被换行拆散的“评 级”。

## 做了什么（输出）

`output/问题1_评级提取结果.xlsx`，17,712 行，列：

| 列 | 说明 |
|----|------|
| fordate / 序号 / stkcd / 公司简称 / 证券公司 / 分析师姓名 | 原始信息 |
| 评级_原始 | 文中原词（如“买入-A”“强烈推荐”“谨慎增持”） |
| 评级_标准化 | 基准档位（买入/推荐/增持/中性/持有/减持/卖出/回避/观望） |
| 评级动作 | 维持/给予/上调/下调/重申/建议/调整/首次/纳入 |
| 提取证据 | 评级词附近的上下文片段，供人工复核 |
| 提取状态 | 已提取（含方法）/未给出评级/未提取到评级/文本为空 |

## 结果如何

| 提取状态 | 行数 | 占比 |
|----------|------|------|
| 已提取 | 15,892 | 89.7% |
| 未提取到评级 | 1,736 | 9.8% |
| 未给出评级（文中明确未给） | 72 | 0.4% |
| 文本为空 | 12 | 0.07% |

标准化评级分布（已提取部分）：买入 42.2%、推荐 34.2%、增持 17.9%、中性 3.7%、
持有 1.9%、卖出 0.2%、观望/减持 <0.1%。

**质量验证**：随机抽查 100+ 行“提取证据”全部正确；对新增句式（裸评级/建议/
截断/兜底）各抽查 30 行无误判。剩余“未提取”行抽样确认均为文中确实无评级档位
的报告（深度报告、事件点评、中金式“维持对该行的评级不变”、仅“建议持续关注”等）。

## 已知局限

1. 一份研报覆盖多只股票时，优先取带动作词、靠近“公司简称”、位置靠后的候选，
   可能偶有归属偏差，请以“提取证据”列复核；
2. 少数报告评级档位完全不在正文中（如“维持评级不变”“跟踪评级”），无法从
   文本中恢复，标记为未提取；
3. “评级”一词在原文中被完全截断（连“评”字都没留下）的极少数行无法恢复。
