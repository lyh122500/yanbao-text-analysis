将以下两个文件放入本目录后运行脚本。字表由项目使用者提供，原始出处和再分发许可尚未在文件中记录，因此仓库不收录字表内容。

| 文件 | 要求 | 本次使用文件SHA-256 |
|---|---|---|
| `现代汉语常用字表_一级常用字2500.txt` | 2500个唯一汉字 | `f5b01057b18877d285a7f0d172fc143f809272bb3d0a22167e7ba7bab4bbfcf0` |
| `现代汉语常用字表_次常用字1000.txt` | 1000个唯一汉字 | `9ca99a7e7a23774f05a91a9235f404b41ea2282bffd84733337d3b1118169a8e` |

UTF-8编码，每行第一列是单个汉字，以空白分列；拼音及后续列不参与计算。两表不得重叠。程序自动检查行数、唯一性和汉字格式。

复用仓库中的`output/reference.json`时，文件哈希必须与上表一致。不同排版即使汉字相同也会改变文件哈希；使用不同版本须重新核验，并明确建立新的参考分布，不能当作原结果复现。
