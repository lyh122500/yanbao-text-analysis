# 问题3：复杂性与可读性

## 怎么做

实现两个**表层语言代理指标**，只依赖Python标准库与openpyxl，不调用大模型、不训练分类器、不依赖问题1/2结果。指标不能解释为读者实际理解能力、教育年限或王克敏等（2018）的原式复现。

### 根据实际数据作出的选择

本批17,712条文本的原始字符数中位数929，95分位2,335。正文中大量使用EPS、百分比、年份、金额与分号，5,528条有`<?>`分隔符。采用汉字计数而非受金融用户词典影响的分词长度，保护小数和千分位；保留数字串密度为辅助列，不假定数字多一定更难读。

已有两份字表经检查分别为2,500个和1,000个不重复汉字、彼此无交集。文件含拼音等列，程序只读取每行第一列。字表由项目提供，其原始出处尚未在文件中记录，因此保存原文件SHA-256以锁定本次输入，但不声称已独立核实字表版本。

不直接使用cntext的Fog/SMOG英文公式，也不将所有长金融词当作难词。缺少完整可核实的逆接与金融术语资源，故没有临时补一套词表冒充文献复现。

### 1. 复杂性：句子有多长、内部有多少段

两个原始特征：

- **句均汉字数**＝全文句子汉字数之和÷句数。
- **句均分段数**＝逗号、分号、冒号划分出的含汉字段数÷句数。

“分段”只是标点分段，不声称是语法分析得到的从句。采用参考样本中的中秩百分位P(x)：`100×(小于x的数量＋0.5×等于x的数量)/参考样本数`。

**复杂性_代理＝[P(句均汉字数)＋P(句均分段数)]/2**。

取值0—100，越大表示句子较长、内部标点分段较多。两个成分相关，等权是透明的设计选择，不是估计出的最优权重。原始成分全部保留，研究时可分别使用。

### 2. 可读性：每段阅读长度与汉字熟悉度

两个原始特征：

- **分段均汉字数**＝所有含汉字段的汉字总数÷标点分段数。
- **非一级常用字比例**＝(次常用字出现次数＋3500字表外汉字出现次数)÷参与字表统计的汉字数。

字表统计前仅排除当前公司简称的完整精确匹配，减少公司名字造成的误差；结构计数保留公司名。次常用字与表外字另有独立计数和比例。

**阅读负担_代理＝[P(分段均汉字数)＋P(非一级常用字比例)]/2**。

**可读性_代理＝100−阅读负担_代理**，越大表示相对更易读。它不是复杂性分数取反，但两者也不是独立构念；本样本两者Pearson相关为−0.112。

百分位在当前合格样本拟合一次，保存为`reference.json`。重复计算或加入新数据时应通过`--reference`复用，而不是重新排名。0—100为相对位置尺度，不是“理解正确率”。本批平均分恰为50是中秩变换的数学结果，不是关于研报质量的实证发现。

### 3. 文本范围与清洗

- 全文口径：保留风险段、评级论述，不复用问题2的风险段删除规则。分析的是当前提供的文本，不假定是完整研报。
- Unicode NFKC规范化全角字符；去零宽字符；统一软连字符和破折号。
- 将`<?>`与空白行作为明确边界；普通换行视为排版换行，不默认断句。
- 删除独占一行的固定标题：财报点评、公司研究、公司点评、投资要点、投资摘要、风险提示、风险因素、公司简评。标题后的文字保留；嵌入正文的标题不猜测删除。
- `。！？!?`为主句末；英文句点仅在前方为汉字或指定闭引号且后面不是数字时切分，不拆`0.64`。小数、千分位不拆为句/分段。
- 不满100汉字或3句：标记短文本，只给原始统计，不给综合分数。
- 最长句超500汉字、疑似多处目录点线或字表分母为零：需复核，不给综合分数。100/3/500是本项目质量筛选规则，不是文献阈值。
- 空值及“无/暂无/无内容”等占位内容不计分、不填0。

普通换行和标题粘连仍可能影响分句，因而额外输出“复杂性_分号分句对照”：把分号也视为句末，沿用主口径参考分布。本批主/对照相关0.753，差异不可忽略。应在后续实证中同时检查，不能把主指标当作对分句完全稳健的结论。

## 做了什么

`problem3_complexity.py`：读根目录原始Excel，按原行序输出；新增`源Excel行号`保证连接可追溯。原表只读，不修改问题1/2。

输出目录：

- `问题3_复杂性可读性结果.xlsx`：逐篇结果、原始成分、质量状态、对照分数及复核片段。
- `结果明细.json`：未经显示格式舍入的机器可读结果。
- `reference.json`：固定的四个特征参考分布，含输入及字表哈希。
- `summary.json`：状态、描述统计和分号敏感性。
- `manifest.json`：代码、数据、字表、参考分布、结果哈希及Python/openpyxl版本。

Excel主列：`复杂性_代理`、`可读性_代理`，其余分项用于解释与稳健性。比例以0—1保存并用百分比显示，代理分数以0—100数值保存。证据最多保留500字符，完整文本在源Excel相同行；命中字列给频次最高15个非一级字，不是全部字表。

### 运行

首次克隆需放回根目录原始Excel及两份字表，字表格式和校验值见[dict/README.md](dict/README.md)。仓库保留Excel结果和四份复现/验证JSON；24MB的`结果明细.json`仅在本地生成，不纳入版本控制。

```bash
# 项目根目录；沿用现有环境，无新增依赖
.venv/bin/python problem3_复杂性可读性/problem3_complexity.py

# 严格复用本次参考分布；新样本也使用此方式
.venv/bin/python problem3_复杂性可读性/problem3_complexity.py \
  --reference problem3_复杂性可读性/output/reference.json

# 将复跑结果写入另一个目录比较
.venv/bin/python problem3_复杂性可读性/problem3_complexity.py \
  --reference problem3_复杂性可读性/output/reference.json \
  --output-dir /tmp/yanbao_problem3_replay

.venv/bin/python -m unittest discover -s problem3_复杂性可读性 -p 'test_*.py' -v
```

## 结果如何

| 状态 | 行数 |
|---|---:|
| 可计算 | 17,574 |
| 文本为空 | 12 |
| 占位文本 | 32 |
| 短文本 | 45 |

可计算记录的复杂性中位数49.532、可读性中位数49.597。复杂性与篇幅（汉字数）相关0.195，可读性与篇幅相关−0.212；不能据此宣称已消除篇幅影响。

人工阅读极端例子：

- 源行5146（三安光电）复杂性接近100，长句内连续列举营收、毛利、费用与盈利判断，分段多；源行1617（祁连山）也很高，但含标题/正文粘连，提醒高分可能同时反映文本抽取问题。
- 源行5400（闰土股份）可读性低，出现大量“氟、苯、氯、醚”等化学名称；符合一般读者字词负担高的解释，但不能据此判断其研报写作差。
- 源行10608（海通证券）可读性高，汉字段落短且多常用字，但仍含专业金融内容。该指标没有测量专业概念理解难度。

测试覆盖字表读取、全角数字、小数/千分位、换行、边界、占位内容、公司名排除、计数守恒、百分位并列、冻结参考分布与结构变化。详见`test_problem3.py`。全量另目录复跑后，17,712行JSON逐字节一致，结果哈希相同；Excel行数、数值类型、缺失状态和计数守恒均已核对，记录见`output/verification.json`。

## 使用边界

本实现完成可复现的表层测量，没有完成读者理解实验。尤其化工/医药专名、其他公司名和地名仍会影响字表熟悉度；当前数据没有行业字段，不能虚构行业调整。后续跨行业比较需增加行业控制或分层，原始分项应一并保留。

代码不会把情感词典注入分词器，因此问题2的词典和全局jieba状态不会改变问题3结果。参考分布如果重建，分数会改变；新研究应明确是复用参考还是重新标定。
