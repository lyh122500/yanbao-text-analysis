# 问题3：复杂性 / 可读性

**需求**（需求文档第 3 条）：生成复杂性和可读性两个指标。

## 怎么做（计划）

- **可读性**：用中文文本分析工具 cntext 库（知乎文章：
  “中文文本分析工具——cntext 库”）计算可读性指标；
- **复杂性**：参考 王克敏、王华杰、李栋栋等（2018）《年报文本信息复杂性与管理者自利
  ——来自中国上市公司的证据》（管理世界，34(12): 120–132）的做法，指标构成为：
  - 逆接成分密度：廖秋忠（1986）《现代汉语篇章中的连接成分》，6 大类 48 个字词；
  - 专业术语密度：《高盛财经词典》（用户提到“行业术语”是后续扩展到各行业）；
  - 次常用字占比：《现代汉语常用字表》（一级常用字 2500 + 二级次常用字 1000）；
  - 备选参考：[tsproisl/textcomplexity](https://github.com/tsproisl/textcomplexity)
    （不确定是否适配中文）。
